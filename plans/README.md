## Findings considered and rejected

(So nobody re-audits these.)

- **"localStorage key collision when `persistenceKey` is omitted"** — wrong:
  every read/write path in `useSandboxState.ts` guards on `persistenceKey`
  (lines 42, 52, 69); omitting the key is the documented ephemeral mode.
- **"Replace `postMessage(..., '*')` targetOrigin with a real origin"** —
  would break the component: the sandbox iframes are `srcDoc` without
  `allow-same-origin`, so their origin is opaque and `'*'` is the only valid
  targetOrigin. The correct hardening (event.source checks) is plan 002.
- **"Vitest 4 / Vite 5 incompatibility"** — misdiagnosis (Vitest 4 post-dates
  Vite 5 and bundles its own pipeline). The real, small issue — `defineConfig`
  imported from `'vite'` instead of `'vitest/config'` — is fixed in plan 001.
- **"Deduplicate react.ts/react-ts.ts and express runner templates via factory
  functions"** — superseded: those files are an unreferenced legacy layer;
  plan 003 deletes them instead of abstracting them.
- **Express route-param regex robustness** (`express.ts:79-90`) — real but
  marginal: a count-mismatch yields `undefined` params, same as several edge
  cases in real Express; not worth a plan.
- **Prettier / husky / pre-commit hooks** — low leverage for a solo-maintained
  repo once CI (plan 001) exists.
- **Playwright E2E for iframe execution** — acknowledged as the largest real
  test gap (also flagged in CLAUDE.md), but explicitly not selected for
  planning in this round. Revisit before any large runtime refactor.
- **Direction options presented and not selected** (no plans written): wiring
  the unshipped SQL mode (consequently `sql.ts` is deleted by plan 003 —
  recoverable from git history but would need porting to the `ENV_RECIPES`
  format); HTTP method selector + request body for ServerOutput; reviving the
  disconnected HelpSidebar with docs for all modes; share-code-via-URL.
- **npm audit findings** (5 dev-only advisories, 1 high: picomatch ReDoS) —
  handled as a step inside plan 001, not a separate plan.
